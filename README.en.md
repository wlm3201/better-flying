# Better Flying

English | [简体中文](README.md)

A Minecraft Fabric client mod that improves creative and spectator flight: a flight toggle keybind,
optional double-tap-jump to fly, flight inertia, horizontal/vertical speed multipliers, a Ctrl
boost multiplier and more.

Ported from chylex's [Better Controls](https://github.com/chylex/Better-Controls) and rewritten
for 26.x.

### Keybinds

The mod adds one key, **unbound by default**: set it in
Options → Controls → Key Binds → Better Flying.

#### Feature toggles

| Setting | Default | Description |
| --- | --- | --- |
| Double tap jump to fly | `true` | Disables the vanilla double-tap-jump flight toggle |
| Flying on ground | `false` | Stay flying when you land. **Double tap sneak** to land |

#### Flight inertia

| Setting | Default | Range | Description |
| --- | --- | --- | --- |
| Flight inertia | `1.0` | 0 – 1 | Lower values decelerate faster after releasing a movement key |

#### Creative mode speed multipliers

| Setting | Default | Range |
| --- | --- | --- |
| Horizontal speed — normal | `1.0` | 0 – 8 |
| Horizontal speed — sprint | `2.0` | 0 – 8 |
| Vertical speed — normal | `1.0` | 0 – 8 |
| Vertical speed — sprint | `2.0` | 0 – 8 |

#### Spectator mode speed multipliers

| Setting | Default | Range |
| --- | --- | --- |
| Horizontal speed — normal | `1.0` | 0 – 8 |
| Horizontal speed — sprint | `2.0` | 0 – 8 |
| Vertical speed — normal | `1.0` | 0 – 8 |
| Vertical speed — sprint | `2.0` | 0 – 8 |
