# Better Flying · 飞行增强

[English](README.en.md) | 简体中文

一个 Minecraft Fabric 客户端模组，为创造模式与旁观模式的飞行功能提供一系列增强：包括飞行切换键、关闭双击跳跃飞行、飞行惯性调节、水平/垂直飞行速度、Ctrl加速倍率等。

本项目移植自 chylex 的 [Better Controls](https://github.com/chylex/Better-Controls)，并针对26.x版本重写。

### 键位

模组新增一个按键，**默认未绑定**，需到「选项 → 控制 → 按键设置 → 飞行增强」中设置。

#### 功能开关

| 配置项           | 默认值  | 说明                                   |
| ---------------- | ------- | -------------------------------------- |
| 双击跳跃切换飞行 | `true`  | 关闭双击跳跃键飞行功能。               |
| 贴地飞行         | `false` | 落地时保持飞行状态。**双击潜行**落地。 |

#### 飞行惯性

| 配置项   | 默认值 | 范围  | 说明                             |
| -------- | ------ | ----- | -------------------------------- |
| 飞行惯性 | `1.0`  | 0 – 1 | 数值越低，松开移动键后减速越快。 |

#### 创造模式速度倍率

| 配置项          | 默认值 | 范围  |
| --------------- | ------ | ----- |
| 水平速度 - 默认 | `1.0`  | 0 – 8 |
| 水平速度 - 疾跑 | `2.0`  | 0 – 8 |
| 垂直速度 - 默认 | `1.0`  | 0 – 8 |
| 垂直速度 - 疾跑 | `2.0`  | 0 – 8 |

#### 旁观模式速度倍率

| 配置项          | 默认值 | 范围  |
| --------------- | ------ | ----- |
| 水平速度 - 默认 | `1.0`  | 0 – 8 |
| 水平速度 - 疾跑 | `2.0`  | 0 – 8 |
| 垂直速度 - 默认 | `1.0`  | 0 – 8 |
| 垂直速度 - 疾跑 | `2.0`  | 0 – 8 |
